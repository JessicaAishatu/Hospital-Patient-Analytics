## Analysis window

**Selected window: 2011-01-01 to 2021-12-31, inclusive.**

The dashboard describes a defined period of simulated hospital operations rather than each patient's entire lifetime history. The full source tables will be retained in the database; the window will be applied in SQL views and Power BI.

- Total encounters: 61,459
- Encounters retained in the window: 34,640
- Encounters before 2011: 26,819
- Encounters from 2022 onward: 0
- Encounters with missing or invalid START: 0

Data-quality log decision: analysis window: 2011–2021; 26,819 encounters before 2011 excluded because the dashboard describes recent operations, not lifetime history. The full tables remain available for other analyses.

## Interpretation and limitations

- The dataset is synthetic and should not be interpreted as evidence about a real hospital or population.
- Missing patient DEATHDATE values are treated as indicating that the patient was alive at the end of the simulation.
- Missing encounter REASONCODE values are retained as null and will not be used in dashboard indicators. The top-ten diagnosis chart will be based on the conditions table.
- Missing condition STOP values are retained as null because they can represent ongoing simulated conditions.
- Identifier-like patient fields will be assessed for removal during the cleaning stage.

## Scope of this profile

This document records initial profiling results. It does not represent completion of the cleaning process. Date validation, relationship validation, and other cleaning decisions will be documented separately.
